# 📊 Retail Sales Analysis & Business Intelligence Dashboard

## 📌 Project Overview

This project analyzes retail sales data to identify sales trends, regional performance, product performance, customer segment contribution, and category-level performance.

The project was developed as a practical **Data Analytics portfolio project** using Microsoft Excel. The analysis transforms raw retail transaction data into meaningful business insights through data cleaning, PivotTables, calculations, and an interactive-style dashboard.

The project uses a Superstore-style retail dataset containing **9,800 sales records** covering the period **2017–2020**.

---

## 🎯 Business Objective

The main objective of this project is to analyze retail sales performance and answer important business questions such as:

- What is the total sales generated?
- How many unique orders were placed?
- What is the average order value?
- Which region generates the highest sales?
- Which product category performs best?
- How do sales change throughout the year?
- Which products generate the highest sales?
- Which customer segment contributes the most sales?
- Which sub-categories generate the highest sales?

The analysis can help businesses understand sales performance and identify areas requiring further attention.

---

## 🗂️ Dataset Information

The dataset contains retail transaction-level sales information.

### Dataset Size

- **Rows:** 9,800
- **Columns:** 18
- **Time Period:** 2017–2020

### Main Columns

| Column | Description |
|---|---|
| Row ID | Unique row identifier |
| Order ID | Customer order identifier |
| Order Date | Date when the order was placed |
| Ship Date | Date when the order was shipped |
| Ship Mode | Shipping method |
| Customer ID | Customer identifier |
| Customer Name | Customer name |
| Segment | Customer segment |
| Country | Country |
| City | Customer city |
| State | Customer state |
| Postal Code | Postal code |
| Region | Sales region |
| Product ID | Product identifier |
| Category | Product category |
| Sub-Category | Product sub-category |
| Product Name | Product name |
| Sales | Sales amount |

> Note: The dataset does not contain Profit or Quantity columns, so the analysis focuses on sales-related metrics rather than profit or quantity analysis.
